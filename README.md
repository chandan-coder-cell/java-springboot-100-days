# 🚀 100 Days Java → Spring Boot Challenge

> My 100-day journey from Java fundamentals to Spring Boot Backend Development.

## 🎯 Goal

The goal of this challenge is to build a strong foundation in Java and Backend Development and become confident enough to build real-world Spring Boot applications.

By the end of 100 days, I aim to learn:

- ☕ Core Java
- 🧩 OOP
- 📦 Collections
- ⚡ Modern Java
- 🗄️ SQL & MySQL
- 🌐 HTTP & REST API
- 🔧 Maven
- 🐙 Git & GitHub
- 🧪 Postman
- 🌱 Spring Framework
- 🚀 Spring Boot
- 🗃️ Spring Data JPA
- 🔥 Hibernate
- 🔐 Spring Security
- 🎫 JWT
- 🐳 Docker
- ☁️ AWS Deployment
